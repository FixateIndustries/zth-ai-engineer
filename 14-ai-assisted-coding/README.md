# Module 14: AI-Assisted Coding

You've spent this course building with models. This module is about building *alongside* them. AI coding tools now range from autocomplete to agents that take a ticket and open a pull request. Knowing which kind to use, and how to keep the result correct, is a daily skill for an AI engineer. You'll also recognise everything under the hood: agent loops, tools, context files and MCP.

**You'll be able to:**
- Place the major tools (Claude Code, Gemini CLI, Codex, Cursor, Devin, Replit Agent) into categories and pick one for a job
- Give a coding agent good context with a `CLAUDE.md` / `AGENTS.md` file
- Work in small, reviewable, test-guarded steps
- Review AI-written code critically and know when not to trust it

**Prerequisites:** [Module 8: Agents](../08-agents/README.md) and [Module 9: MCP](../09-mcp/README.md) help you understand how these tools work. [Module 13](../13-safety-and-ethics/README.md) covers the security side.

# Module 3: Choosing Models

There are hundreds of models, and new ones ship every week. Picking one is an engineering decision with real consequences for quality, cost, speed and privacy. This module maps the landscape (closed and open models), shows you how to run open models on your own machine and through Hugging Face, and gives you a repeatable way to choose: shortlist, test on your own examples, and pick the cheapest model that passes.

**You'll be able to:**
- Explain the difference between closed models, open-weight models and open-source models, and read a model license for the parts that matter
- Run an open model locally with Ollama or LM Studio and estimate whether it fits your hardware
- Find models on the Hugging Face Hub and run them with `transformers`, Transformers.js or Inference Providers
- Choose a model with a simple framework instead of a leaderboard, and compare candidates side by side through OpenRouter

**Prerequisites:** [Module 2: Calling Models](../02-calling-models/README.md), especially [OpenAI-compatible APIs](../02-calling-models/02-openai-compatible-apis.md).

# Module 10: Multimodal AI

So far everything has been text in, text out. Real users send screenshots, photos of whiteboards, scanned invoices, voice notes and video clips, and some products need to answer with images or speech. This module shows you how to get those modalities into and out of models, which provider does what, and when to use one native multimodal model versus a pipeline of specialists.

**You'll be able to:**
- Recognize multimodal use cases and map them to concrete task types
- Send images (and video) to a model and get structured answers back
- Generate and edit images with the OpenAI and Gemini image models
- Transcribe speech and synthesize it, and chain both around an LLM
- Use Hugging Face pipelines, LangChain or LlamaIndex to build multimodal apps

**Prerequisites:** [Module 2: Calling Models](../02-calling-models/README.md) (API calls and structured output). [Module 3](../03-choosing-models/README.md) helps for the Hugging Face parts.

# Module 4: Prompt Engineering

A prompt is the interface between your code and the model. The same model can be useless or excellent depending on how you ask, so prompt writing is a core engineering skill, not a party trick. In this module you'll learn to structure prompts, teach by example, get the model to reason before it answers, and treat prompts like code you version and test.

**You'll be able to:**
- Break a prompt into its parts (role, context, task, constraints, output format) and fix a weak one
- Choose between zero-shot and few-shot prompting, and write good examples
- Use chain-of-thought and ReAct-style prompting, and know when built-in reasoning makes them unnecessary
- Store prompts as versioned templates and check changes against a set of examples

**Prerequisites:** [Module 2: Calling Models](../02-calling-models/README.md) (you should be comfortable making an API call and reading the response)
